    Installation Guide

    From a fresh Discord install to your own Hotori setup. Already finished a step? Continue with the next one.

    1. Start with Discord for Windows

      Install the Discord desktop app and sign in. Open it at least once before installing Vencord. This guide is for the Windows desktop app.

    2. Install Vencord

      Choose Download Vencord below to open vencord.dev in your browser. Download VencordInstaller.exe, run it normally (not as administrator), select your Discord installation, and choose Install. If you use more than one Discord version, select the one you actually open.

      Fully quit Discord, including its system-tray icon, then reopen it. In Discord’s User Settings, look for the Vencord section. If it is missing, check that you patched the correct Discord installation.

    3. Install the Hotori theme

      Return to Hotori and close this guide. Fully quit Discord, including its system-tray icon, then choose Install at the top of the dock. Hotori installs the theme and automatically enables it in Vencord; you do not need to copy CSS or turn on a theme switch yourself.

      If Install stays unavailable, open Discord once after installing Vencord, then reopen Hotori.

    4. Open Discord with Hotori enabled

      Reopen Discord after installation. Hotori is already enabled. You can check its switch under User Settings → Vencord → Themes → Local Themes. Other themes stay enabled; turn off other full themes there if their styles overlap with Hotori.

    Additional info

    • Customize your appearance

      Choose Customize in Hotori’s dock, then pick a category on the left. In Glass Appearance, choose Acrylic, Liquid Glass, or No Glass and adjust the available blur, color intensity, and tint controls. Avatars controls avatar size and roundness; Messages includes mention highlights.

      Use the save button at the bottom of the right panel after editing each category. Switching categories keeps your drafts; Back discards unsaved changes. If Discord does not reflect a saved change, restart Discord.

    • Choose and crop your wallpapers

      In Wallpapers, choose a local image, use a direct image link, or paste an image into the wallpaper control. Drag the crop preview to position your image and use the zoom slider or mouse wheel to zoom. Main Background uses 16:9; Settings Background uses the settings panel’s nearly square proportions.

      Choose Use crop, check the preview, then Save Wallpapers. Main Background has an illustrative Discord layout preview; Settings Background has an image preview. Use Crop & zoom to adjust an image again. Each wallpaper has its own top and bottom dimming controls.

      Your saved Main Background also becomes Hotori’s app wallpaper. The brightness icon below the dock changes only the app’s background overlay; it does not change your Discord theme.

    • Pick colors from your wallpaper

      Your Main Background supplies recommended colors. Try the two quick swatches beside Clear background, or open Colors → Main Color for more recommendations and color controls. Settings Background does not affect the recommendations.

      Recommended mention colors stay under Messages → Mention Highlights. A pulsing white dot marks categories with new recommendations until you visit them. Clicking a recommended swatch applies and saves that color immediately; other unsaved edits stay in the editor.

    • Arrange servers and the Friends sidebar

      In Server List, choose a vertical or horizontal server layout. Under Friends Sidebar, choose Hidden or Shown, then save the category. Hidden removes the persistent right-side Friends sidebar and its reserved space; your main Friends page and server member list remain available.

      The Friends Sidebar option requires theme 0.8.16 or newer. Update your theme first if the option is missing.

    • Keep the theme and app current

      The Installed theme bubble shows your theme version and its release notes. When a theme update is available, choose the update notice beside the version. Theme updates preserve your supported customization settings.

      Hotori checks for app updates when it opens. If a newer app version is available, a liquid-glass prompt offers Not now or Download & restart. The separate Update Hotori dock button also opens the app update dialog. Download & restart closes and reopens Hotori while keeping your theme settings and wallpapers.

    • Reset or uninstall when needed

      Reset to defaults restores and saves the default settings across all categories, including wallpapers. Review its confirmation prompt before continuing; Cancel keeps your current setup and drafts.

      Uninstall theme also asks for confirmation before removing the theme and its saved customizations. You can install Hotori again later.

    Reset to defaults?

    This restores and saves the default theme settings across all categories, including wallpapers. Your customizations and unsaved changes will be reset.

    Uninstall Hotori?

    This removes the theme and its saved customizations from Vencord. You can install Hotori again later.
